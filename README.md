# Portal do Bicho

Portal informativo e demonstrativo para consulta de resultados, ferramenta de combinações de milhar e tabela dos 25 grupos.

## Publicação

O projeto é estático (HTML, CSS e JavaScript), sem dependências ou etapa de compilação. Para publicar com GitHub Pages:

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Salve e aguarde a publicação.

## Importante

Os resultados exibidos são dados fictícios para demonstração. O projeto não está conectado a fontes oficiais nem realiza apostas. Não interpretar números ou combinações como previsões.

## Arquivos

- `index.html`: estrutura e seções do portal.
- `styles.css`: layout responsivo.
- `app.js`: filtros, tabela de grupos, resultados demonstrativos e ferramenta de milhar.
